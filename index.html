Using VAX Designer

Edit a sentence
  1. Connect Kraftor through USB using Connect Kraftor.
  2. Select a slot on the right. Its sentence and voice settings appear on the left.
  3. Type a sentence or use Bulk paste… for one sentence per line. The old @one@two@three format is also accepted in bulk paste.
  4. Adjust the voice and sliders. Audition draft plays the unsaved settings. Save to Kraftor writes that slot to FRAM.

Play saved slot plays its stored profile. Reset voice settings restores the controls and speech rate 75 while keeping the sentence and selected voice.

You can select slots with the keyboard: Tab to a slot number, then use the arrow keys, Enter or Space.

DECtalk native format: speech, phonetics and singing

The Sentence box accepts real DECtalk commands and phonetics directly. Voice and slider settings are applied first; your native sentence follows unchanged. Type or paste these examples into the same Sentence box. Click Audition draft to listen, then Save to Kraftor to keep the phrase.

Ordinary speech
Hello from Kraftor.

[:command value] changes a setting. [phonemes] spells sounds instead of words. Begin a phonetic phrase with [:phoneme arpabet speak on] to enable phoneme interpretation.

Control a pronunciation
[:phoneme arpabet speak on]Say [r 'ow b aa t].

The bracketed sounds say “robot”. The straight apostrophe marks primary stress. Close every bracket before returning to ordinary words.

Add a half-second pause
[:phoneme arpabet speak on]Ready [_<500>] now.

_ is silence; <500> lasts 500 milliseconds.

Sing three notes on “ah”
[:phoneme arpabet speak on][aa<500,25> aa<500,29> aa<1000,32>]

phoneme<duration,pitch>: duration is milliseconds. Pitch numbers 1–37 select musical notes: 25 = C4, 29 = E4, 32 = G4. These are DECtalk tone numbers, separate from the MIDI note that triggers the slot.

Change speed within a sentence
[:rate 100]Slow first. [:rate 180]Faster now.

[:rate] accepts 75–600 words per minute.

Set an inline voice design
[:dv ap 90 pr 0]A steady robot voice.

ap sets average pitch in Hz; pr 0 removes pitch variation. Keep [:dv ...] around inline design parameters; ap 90 pr 0 alone is ordinary text. When using sliders, the Designer builds the design command for you.

The Designer applies the selected voice and sliders before your sentence. Inline commands come afterwards and can override those settings or live MIDI CCs; sliders do not display values embedded in your text. Reset voice settings keeps the sentence, so remove inline commands there to stop using them.

Commands and brackets count toward the 200-character sentence limit and the slot's byte budget. Use plain ASCII characters. /r, /v and /d belong in the legacy serial terminal; use [:...] here. Bulk paste accepts one complete native phrase per line. Serial audition also sends a complete native DECtalk phrase; the manual serial terminal keeps its older slash commands.

Drafts, saved memory and temporary RAM

Drafts live in this browser session until you save them. Saved FRAM slots survive a restart. Bulk paste loads drafts and keeps each destination's voice settings; it does not write memory automatically.

The bank holds 100 slots. Slots 0–91 are triggered by MIDI notes 36–127. Slots 92–99 play from the Designer only.

The separate legacy serial @ parser holds at most 12 temporary RAM phrases. Those phrases disappear on restart and can override their matching MIDI notes while loaded. They are not the FRAM bank.

Sentences use ASCII text, up to 200 characters. Text and voice parameters together must fit the slot's 248-byte budget. Invalid bulk pastes are rejected as a whole.

MIDI channel and physical switches

The four physical switches select channels 1–16: all OFF is channel 1 and all ON is channel 16. The channel is the binary switch value plus one. Restart Kraftor after changing switches, then click Refresh. The on-screen switches are read-only.

MIDI CC controls — VAX firmware 1.3

Send these CCs on Kraftor's MIDI channel. They affect the next MIDI-note-triggered phrase, without changing saved memory. Designer sliders edit slot drafts independently.

Print and backup

Print saved slots rereads physical FRAM and prints only populated saved slots, with their exact stored sentence and voice profile. Drafts, temporary serial RAM phrases and live CC overrides are not included.

Export backup exports the saved bank as JSON. Import first loads a backup locally; Restore writes it to Kraftor. Format erases the bank and asks for confirmation.

For earlier firmware or a serial terminal, open Older firmware / serial tools at the bottom of the editor.
